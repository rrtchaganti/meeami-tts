How it works: the text is normalized and looked up in one fixed US lexicon; MFA aligns the text to the recording to get each word's start and end; each model uses its own native durations inside every word, stretched to the word's span, so the accent of the recording never leaks in; the waveform is cut to exactly the recording's length. "Measured" times come from MFA run on each output, as in the evaluation.
